### Challenge 5: Prime Number Checker

**Topics: Functions, Loops, Logical operators, Modulo**

Create a program with:

- `bool isPrime(int number)` - returns true if number is prime
- `void printPrimesInRange(int start, int end)` - prints all primes in range
- In `main()`, ask user for a range and display all prime numbers

**Optimization challenge:** Make `isPrime()` efficient (only check up to sqrt of number)
