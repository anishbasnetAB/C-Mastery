Level 2: Intermediate (Medium)

### Challenge 3: Number Guessing Game

**Topics: Loops, Random numbers, Control flow, If statements**

Create a number guessing game:

- Generate a random number between 1-100 using Mersenne Twister
- User has 7 attempts to guess
- After each guess, tell them if they're too high or too low
- If they win, tell them how many guesses it took
- If they lose, reveal the number
- Ask if they want to play again (loop the entire game)
