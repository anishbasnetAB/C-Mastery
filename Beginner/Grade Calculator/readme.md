### Challenge 2: Grade Calculator

**Topics: Functions, If statements, Local variables**

Write a program with these functions:

- `char getLetterGrade(int score)` - returns 'A' (90+), 'B' (80-89), 'C' (70-79), 'D' (60-69), 'F' (<60)
- `bool isPassing(char grade)` - returns true if grade is not 'F'

In `main()`:

- Get a numeric grade from user
- Display the letter grade
- Display whether the student passed
