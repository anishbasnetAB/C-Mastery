### Challenge 1: Temperature Converter

**Topics: Functions, I/O, Operators**

Write a program that:

- Has a function `double celsiusToFahrenheit(double celsius)` that converts Celsius to Fahrenheit
- Has a function `double fahrenheitToCelsius(double fahrenheit)` that converts Fahrenheit to Celsius
- In `main()`, ask the user which conversion they want (1 or 2)
- Get the temperature value and display the result
