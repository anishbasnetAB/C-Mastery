Exercise 1: FizzBuzz with a Twist (Warmup)
Concepts: Loops, conditionals, modulo operator, logical operators
Write a program that prints numbers 1-100, but:

For multiples of 3, print "Fizz"
For multiples of 5, print "Buzz"
For multiples of both 3 and 5, print "FizzBuzz"
For prime numbers, print "Prime" instead of the number
Everything else prints the number

Success Criterion: Correct output for all 100 numbers. Your prime detection better not be brute-force garbage—use efficient logic.
Why this matters: Prime detection shows up in crypto algorithms. If you can't optimize a simple sieve-like approach, you'll write $10M/day trading systems that timeout.
