# C-Mastery

A structured collection of C++ practice projects built while mastering the language from the ground up — covering beginner fundamentals through advanced topics.

## What's Inside

| Folder | Topic |
|--------|-------|
| `Beginner/` | Variables, loops, functions, arrays |
| `Intermediate/` | Pointers, references, string manipulation |
| `Advanced/` | OOP, templates, memory management |
| `Class&Constructors/` | Object-oriented programming concepts |
| `DSA/` | Data structures and algorithms (2-pointer, etc.) |
| `Algorithms/` | Sorting, searching, problem-solving patterns |
| `Order Book Manager/` | Mini-project: stock order matching engine |
| `Student Grade Management System/` | Mini-project: grade tracking system |
| `30 day coding challenge/` | Daily coding exercises |

## Topics Covered

- Core C++ syntax and types
- Pointers and memory management
- Object-Oriented Programming (Classes, Constructors, Inheritance)
- Data Structures & Algorithms
- Problem-solving patterns (two-pointer, sliding window)
- File I/O
- Modern C++ (C++17 idioms)

## How to Run Any File

```bash
g++ -std=c++17 filename.cpp -o output
./output
```
