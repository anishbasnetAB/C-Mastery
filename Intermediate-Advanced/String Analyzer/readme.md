Challenge 6: String Analyzer
Topics: std::string, Functions, Loops, Char operations, Counters

Write a program that analyzes a string input:

int countVowels(const std::string& str)
int countConsonants(const std::string& str)
int countDigits(const std::string& str)
int countSpaces(const std::string& str)
std::string reverseString(const std::string& str)
bool isPalindrome(const std::string& str) - ignoring spaces and case
Get a sentence from the user and display all statistics.
